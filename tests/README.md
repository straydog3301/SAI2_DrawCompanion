# 測試

```bash
python tests/run_tests.py            # 核心 + 介面（介面測試會開出視窗，需要桌面環境）
python tests/run_tests.py --core     # 只跑核心：不開視窗、不連網，約 2 秒
python tests/run_tests.py --network  # 另外跑連網測試（美術館 API）
```

| 資料夾 | 內容 |
|---|---|
| `core/` | `core/` 模組的邏輯：每日任務、課程與學習路徑、成長統計、範本與技能管理、筆刷素材與佇列、PSD、語系檔一致性，並確認 `core/` 不依賴 Tk |
| `ui/` | 以真正的 Tk 視窗操作：任務卡、研究視窗、成長頁、管理視窗與設定、打卡快照、版面尺寸、速寫網路圖源、舊資料升級 |
| `network/` | 需要連網：美術館開放典藏 API 是否仍能取得每堂課的參考圖 |

撰寫規則：
- 每個測試檔都能單獨執行（`python tests/core/test_xxx.py`），失敗時程序回傳非 0，全部通過時印出 `OK n checks`。
- **只使用暫存目錄**，不讀寫使用者的資料檔；介面測試透過 `_helpers.headless_main()` 把資料路徑、全域快捷鍵、錄影執行緒都換成測試用。
- 預設不連網：需要網路的來源以假的函式代替（例如研究視窗的參考圖、速寫的 `urlopen`），真正連網的檢查放在 `network/`。
- 時間相關的邏輯一律傳入固定時間（`now=`），避免測試結果因執行當下的時間而不同。
