# SAI2 DrawCompanion 🎨 (v1.7.0)

`SAI2 DrawCompanion` (繪圖助手) 是一款專門為 **PaintTool SAI Ver.2** 開發的開源輔助工具。它能自動在背景追蹤您的繪圖時間、提供多維度統計圖表，並具備智慧型縮時錄影功能、液化變形工具、速寫練習參考視窗，以及引導練習方向的每日任務與繪圖技能成長紀錄。

## 🌟 主要功能 (Core Features)

### 1. 🕒 高精度時間追蹤 (Draw Time Tracker)
- 自動偵測並累計 SAI2 中各專案/圖檔的「開啟時間」與實際的「動筆作畫時間」（支援繪圖板筆壓與滑鼠按壓偵測）。
- 當您暫停作畫超過設定的閒置時間（例如 10 秒）時，計時會自動暫停，並在您下筆時瞬間恢復，確保數據 100% 精準。
- 依照檔案所在的第一層資料夾**自動群組分類**，亦支援自訂分組。
- **未存檔的新畫布（如「新增版面N」）預設不追蹤**——這類畫布多為貼參考圖用途；若需要追蹤可在設定中開啟「追蹤未存檔的新畫布」。
- 以「主視窗標題」判定目前工作檔案，參考圖的浮動視窗即使在最上層也不會干擾偵測。

### 2. 📈 視覺化統計圖表 (Visual Statistics)
- 內建統計儀表板，支援切換查看：週 / 月 / 三個月 / 六月 / 年 / 至今。
- 視覺化長條圖展示每日總作畫時長、平均作畫時間與單日作畫高峰。

### 3. 🎬 智慧縮時錄影 (Smart Timelapse)
- **僅錄製畫布**：高精度裁切畫布範圍（分頁模式與浮動視窗模式皆完美支援），自動過濾上方選單、調色盤及彈出式對話框，不干擾畫面。**錄製目標會驗證視窗檔名**：切到其他分頁或參考圖的浮動視窗時自動跳過影格，不會錄到別的圖檔。
- **僅錄製畫布（浮動視窗）**：開始錄製時自動對 SAI2 送出 `Ctrl+Alt+N` 為目前畫布開啟新的浮動檢視，並將其移到螢幕外鎖定錄製——類似 CLIP STUDIO 的隱形縮時錄影，主視窗的分頁切換、縮放平移完全不影響錄製內容（需 SAI2 的「新增檢視視窗」快捷鍵為預設的 `Ctrl+Alt+N`）。
- **錄製 SAI 視窗** / **整個螢幕**：提供多種錄製範圍供選擇。
- **動態播放倍數**：支援 1x 到 100x 的作畫加速。

### 4. 🎞️ 四種影片品質規格 (4 Video Quality Presets)
- **輕量空間 (Compact)**：以 JPEG 75% 壓縮畫格，高壓縮率。
- **標準畫質 (Standard)**：以 JPEG 90% 壓縮，畫質與空間的完美平衡（預設）。
- **專業高清 (High-Quality)**：以 JPEG 98% 壓縮，保留極致細節。
- **100% 原畫無損 (Lossless)**：以 PNG 無損格式保存畫格，搭配 FFmpeg CRF 0 合成無損 MP4。

### 5. 📌 最近使用優先 (Recently Active Sort)
- 列表預設會將「最近正在繪製的專案分組與檔案」優先挪到列表第一順位，方便密集開啟編輯。
- 樹狀列表支援點擊標頭欄位（開啟時間、動筆時間、最後使用等）即時進行雙向排序。

### 6. 🗺️ 多語系支援 (Dynamic i18n Support)
- 軟體開箱即內建：**繁體中文 (Traditional Chinese)**、**英文 (English)** 與 **日文 (Japanese)**。
- 支援外部自訂語系：只需將翻譯好的 JSON 語系檔案丟入與 `.exe` 同一層的 `locales/` 資料夾，即可直接在設定選單內切換，**完全不需要重新編譯專案**。
- 當語系檔案有缺漏字詞時，會自動套用英文或中文的對應欄位，保證介面安全回退。

### 7. 🎨 高級主題與 Windows 標題列整合 (Modern Styling)
- 支援深色模式 (Dark Mode) 與亮色模式 (Light Mode) 快速切換。
- 提供 12 種精緻的預設主題色（羅蘭紫、向日葵黃、天空藍等）與自訂 Hex 色碼。
- **標題列整合**：軟體標題列（TitleBar）會自動套用主題模式與主色調。

### 8. 📱 極簡懸浮視窗與快捷鍵 (Mini Widget & Hotkey)
- 提供可任意拖曳、置頂的迷你小標籤，展示目前圖檔的作畫進度。
- 支援全域錄影開關快速鍵（預設為 F10），方便在繪圖時快速暫停或開啟錄製。
- 支援全域速寫練習快速鍵（預設為 `Ctrl + Alt + K`），隨時叫出速寫參考視窗（詳見功能 10）。

### 9. 🌀 液化變形工具 (Liquify / Warp Tool)
SAI2 本身不內建液化功能，本工具提供了一套完整的液化變形方案，讓您無需離開 SAI2 工作流程即可進行變形操作。

**使用方式**：在 SAI2 中先選取要液化的區域，然後按下 `Ctrl + Alt + L` 即可開啟液化編輯器。

**已實現功能**：
- ✅ **推拉變形 (Push)**：用筆刷拖曳即可推動像素，直覺操作
- ✅ **膨脹 (Bloat)** / **收縮 (Pinch)**：按住即可讓區域膨脹或收縮
- ✅ **順時針旋轉 (CW Twirl)** / **逆時針旋轉 (CCW Twirl)**：讓筆刷範圍內的像素旋轉扭曲
- ✅ **重置筆刷 (Reset Brush)**：將筆刷範圍內的變形恢復原狀
- ✅ **平滑筆刷 (Smooth)**：將筆刷範圍內的變形網格往鄰近點平均位置撫平，使扭曲過渡更自然
- ✅ **凍結遮罩 (Freeze Mask)**：先以「凍結」筆刷塗抹要保護的區域（以半透明紅色顯示），液化時該區域不受影響；搭配「解凍」筆刷與「清除凍結遮罩」按鈕管理遮罩，遮罩變更同樣支援 Undo / Redo
- ✅ **液化網格顯示 (Show Mesh)**：可隨時切換顯示底層液化網格（快捷鍵 `M`），便於觀察變形的位置與程度
- ✅ **壓感支援 (Pen Pressure)**：透過 Windows Pointer API（Windows 8+）讀取繪圖板筆壓，動態調整液化強度；可於面板開關，未偵測到手寫筆時自動退回滑鼠模式（狀態列會顯示目前輸入模式）
- ✅ **筆刷大小 / 強度調整**：滑桿調整或快捷鍵 `[` / `]` 調整筆刷大小
- ✅ **Undo / Redo**：支援最多 50 步歷史紀錄，`Ctrl+Z` 復原、`Ctrl+Y` 重做
- ✅ **縮放與平移**：`Ctrl + 滾輪` 縮放、`空白鍵 + 拖曳` 平移畫布
- ✅ **背景模式切換**：棋盤方格 / 純白背景 / 灰色背景，設定自動記憶
- ✅ **自動複製並貼回 SAI2**：套用後自動複製到剪貼簿（含透明度），並模擬 `Ctrl+V` 貼回 SAI2
- ✅ **整層液化模式 (Whole-Layer Liquify)**：在 SAI2 中**不建立選區**直接按快捷鍵，會自動複製目前圖層進行液化並**保證原地貼回**。內部採用「角標錨定法」：先在畫布 (0,0) 自動貼上並合併一顆 1×1 標記像素，使 SAI2 複製時不會裁掉左/上的透明邊界，複製完成後自動 Ctrl+Z 還原圖層（含驗證與自我修復）並清除標記。適合對整個角色圖層修型。注意：目前圖層需為一般點陣圖層（資料夾/特殊圖層無法合併標記，會提示錯誤）
- ✅ **快捷鍵操作**：`Enter` 套用並關閉、`Esc` 取消
- ✅ **設定持久化**：筆刷大小、強度、背景模式、網格顯示與壓感開關自動保存，下次開啟時還原

**尚未實現 / 已知限制**：
- ⬜ **選區模式的原地貼回對齊 (Paste-in-Place)**：自動座標比對機制已強化（v1.4.0 起改用分散式特徵取樣，比對成功率較舊版的角落取樣大幅提升），比對成功時會自動以完整畫布尺寸對齊貼回。經實際調查，SAI2 複製時雖會在剪貼簿註冊私有格式（`A44EB595-...`），但以延遲渲染方式拒絕對外部程式提供內容（`CLIPBRD_E_BAD_DATA`），故**無法取得精確的選區座標**，選區模式只能依靠影像比對；在大面積純色或重複圖樣上比對可能失敗，此時圖像會貼到畫布左上角需手動對齊。若需要保證對齊，請改用**整層液化模式**（不建立選區直接觸發）。
- ⬜ **壓感支援於 Windows 7 不可用**：筆壓偵測依賴 Windows 8 以上的 Pointer API，舊系統會自動退回滑鼠模式。

### 10. ✏️ 速寫練習 (Gesture / Speed Sketch Practice)
一個隨開隨畫的速寫參考視窗，讓你在等靈感或暖手時，隨時抽一張圖配上倒數計時開始練習。可從控制列的 `🎨 速寫練習` 按鈕開啟，或用**全域快捷鍵**（預設 `Ctrl + Alt + K`，可於設定自訂）在任何情況下叫出。

**圖片來源（三選一）**：
- **本機資料夾**：隨機從你指定的參考圖庫抽圖。採「洗牌佇列」——抽完整個資料夾才會重複。可在設定中指定**預設資料夾**，或在視窗內用 `📁 資料夾` 臨時挑選。
- **Unsplash** / **Pexels**：從官方圖庫線上隨機抽圖（實景照片，適合人像、手部、風景、靜物參考）。需在**設定 → 速寫練習**填入各自的免費 API 金鑰（金鑰僅存於本機設定檔，不會上傳或進入版控）。

**練習類型（依來源自動切換）**：
- **網路來源**：內建人像/臉部、姿勢/全身、手部、足部、風景、動物、靜物、建築場景，以及**自訂關鍵字**。
- **本機來源**：自動以參考圖庫**第一層子目錄名稱**作為分類（外加「全部（隨機）」）。例如 `參考圖庫/人像`、`參考圖庫/手部`，分類選單就會出現「人像」「手部」，選了就只抽該子目錄。

**姿勢倒數計時**：30 秒 / 60 秒 / 90 秒 / 2 分 / 5 分 / 10 分 / 不限時，時間到自動翻頁；支援 `⏮ 上一張`、`⏸ 暫停`、`⏭ 下一張`。快捷鍵：`空白鍵` 暫停、`←` / `→` 翻頁。

**灰階模式**：一鍵切換灰階顯示，方便做明度（value）觀察練習。

**精簡模式（沉浸式參考）**：雙擊圖片、按 `Esc` / `Ctrl + M` 或 `🗕 精簡` 按鈕即可切換。精簡模式會隱藏所有介面、**採透明底**只留圖片本身浮在 SAI2 之上（圖片外的留白區可看穿到底下畫布），右上角常駐倒數計時；**滑鼠移入圖片才浮現**上一張/暫停/下一張/還原控制，移開自動淡出。無邊框狀態下可直接拖曳圖片移動視窗，並持續強制置頂（含自我修復，不會被 SAI2 全螢幕搶走）。

**與主視窗連動**：預設開啟「主視窗進入精簡模式時，速寫視窗一起精簡」（可於設定關閉），讓你一個動作就把整組工具收成沉浸式狀態。

### 11. 🖌️ 筆刷、紋理與材質製作工坊 (Brush & Texture Studio)
SAI2 本身缺乏像 Photoshop 或 CSP 那樣「將圖形一鍵登錄為自訂筆刷或材質」的直覺功能。本工具提供了完整的筆刷與紋理製作工作台，讓您隨畫隨轉，一鍵將畫布上的任何圖形轉為現成的 SAI2 筆刷工具、無縫紋理或紙張材質！

**使用方式**：在 SAI2 中選取想要做成筆刷或紋理的圖樣並複製（`Ctrl + C`），按下全域快捷鍵 `Ctrl + Alt + B` 或點擊控制列的 `🖌️ 筆刷` 按鈕即可叫出工坊。

**四種核心製作模式**：
1. **✨ 散布筆刷 (Scatter Brush)**：
   - 適合星光、落葉、雪花、氣泡、碎石斑點等。
   - 支援微調間距 (Spacing)、散布幅度 (Scattering)、隨筆向旋轉、尺寸/角度隨機抖動與筆壓感度。
2. **🖌️ 印章/形狀筆刷 (Shape / Stamp)**：
   - 適合蕾絲、鏈條、特殊筆尖、幾何圖騰、紋理描線筆。
   - 支援四種去背模式（透明度 Alpha、白底黑線、黑底白線、實心剪影）與自動裁切安全留白。
3. **🧶 筆刷紋理 (Brush Texture - brushtex)**：
   - 專門製作套用於筆刷上的微觀紋理（如粗網點、畫布紋、雜點）。
   - 內建**無縫接縫平鋪融合 (Seamless Cross-Fade)** 與 **2×2 鏡像對稱平鋪** 演算法，徹底消除四周拼接接縫。
   - 支援對比度增強 (0.3x ~ 3.0x)、亮度偏移與黑白反轉。
   - **✨ 支援勾選「同時在 SAI2 建立質感筆刷」**：直接為您產生一把預先套用此紋理的作畫工具！
4. **📜 畫布紙張材質 (Paper Texture - papertex)**：
   - 專門製作圖層效果中的「紙張材質」（如水彩紙、和紙、油畫布、素描紙）。
   - 自動無縫平鋪融合處理，並自動註冊至 SAI2 圖層面板的紙張材質下拉選單中。

**即時互動預覽**：
- **3×3 九宮格平鋪即時預覽**：一鍵切換 3×3 重複平鋪，即時觀察紋理連續拼貼效果與接縫消除程度。
- **手感試畫區 (Live Scratchpad)**：內建手繪測試畫布，隨調隨試畫，支援深黑/純白/羅蘭底色切換。

**防覆蓋智慧安全部署**：
- **SAI2 未開啟時**：一鍵同時寫入素材檔（`.bmp` + `.ini`）與工具設定檔（`.saitdat`），自動掛載至目標分頁（基本/二值/效果/自選分頁），下次開啟 SAI2 筆刷直接可用！
- **SAI2 運行中**：提供「待 SAI2 關閉時自動儲存 (推薦)」，將任務加入背景隊列，伴隨 DrawCompanion 的進程監控在 SAI2 結束時自動安全寫入，保證不會被 SAI2 關閉時的記憶體快取覆蓋；亦支援立即強制寫入或僅存入素材庫。

### 12. 📅 每日任務與繪圖技能 (Daily Quests & Skills)
主畫面的「今日任務」卡每天依**平衡課表**排出 1～3 項練習，按「▶ 前往」立即開始，達標後打卡。

**技能 × 練習方式**：8 個繪圖技能（透視、形體結構、人體與動態、明暗光影、色彩、構成、線條筆觸、質感描繪）搭配 5 種練習方式：
- ⚡ **計時速寫**：自動開啟速寫視窗並帶入題目與間隔，倒數自然歸零才算一張。
- 🖌️ **臨摹研究**：每項任務對應一堂課程（共 29 堂、7 條學習路徑），附參考圖、單一學習重點、分段步驟與完成檢查；打卡時自評 3 分以上進到下一課。
- 🔁 **反覆練習** / 🗂️ **縮圖構成**：回報完成數量。
- ⏱️ **創作時長**：以 SAI2 實際動筆時間累計。

**平衡課表**：每日時間預算、先熱身再主練、越久沒練的技能越常出現、可指定「本週主修」、不與昨天重複；每天可「🔄 換一個」，也能「＋ 加入」自選。

**臨摹研究視窗**：參考圖取自大都會博物館與芝加哥藝術博物館的**公有領域**作品，或 Unsplash / Pexels 精選關鍵字、本機圖庫，並標示出處與「為什麼選這張」。提供水平翻轉、灰階、明度分階、主色擷取、構圖輔助線，以及**擷取 SAI2 畫布並排比對**；「🆕 練習畫布」可一鍵建立與參考圖同比例、依課程命名的 PSD 並在 SAI2 開啟。

**打卡快照**：打卡時自動擷取 SAI2 畫布縮圖存入歷史（可在設定關閉）。

**作品技能標籤**：在檔案清單按右鍵「🎨 技能標籤」，平常畫這個檔案的時間也會計入技能。

**任務管理**：任務卡上的「⚙ 管理」可開關、新增、編輯任務範本（內建範本可停用），並建立自訂技能；設定頁的「每日任務」區塊可調整每日數量、時間預算、換日時間、每日可換次數、每週休息日。

### 13. 🎯 成長頁籤 (Growth)

## 🛠️ 開發與編譯方式 (Development & Building)

### 準備工作 (Prerequisites)
1. **Python 3.10+** (確保已勾選加入系統 Path)。
2. **FFmpeg**：由於錄影合成影片需要使用 FFmpeg，請確保本機已安裝且其 `bin` 目錄已被加入到系統的 `PATH` 環境變數中。

### 安裝依賴 (Install Dependencies)
在專案目錄下執行以下指令安裝需要的 Python 套件：
```bash
pip install -r requirements.txt
```

### 打包為獨立執行檔 (Compile to Standalone EXE)
執行 `build.bat`，程式將自動安裝 PyInstaller 並將主程式編譯為單一免安裝的執行檔。編譯完成後，您可以在 `dist/` 資料夾下找到 `SAI2_DrawCompanion.exe` 與對應的 `locales` 語系目錄。
```bash
build.bat
```

## 🚀 使用說明 (Usage)

1. 開啟 `SAI2_DrawCompanion.exe`。
2. 啟動您的 **PaintTool SAI Ver.2**。
3. 開始作畫，程式會自動捕捉目前工作的專案名稱，並開始累積作畫時間與錄製縮時畫格。
4. **自動開機啟動**：您可以執行 `setup_startup.bat`，這將會在系統的啟動目錄中建立捷徑。當 SAI2 開啟時，本軟體將會自動在背景啟動；當 SAI2 關閉時，本軟體也會自動儲存並關閉。若想移除捷徑，只需執行 `remove_startup.bat`。

### 快捷鍵一覽

| 快捷鍵 | 功能 |
|---|---|
| `Ctrl + Alt + L` | 開啟液化編輯器（有選區→液化選區；無選區→自動液化整個圖層並保證原地貼回） |
| `Ctrl + Alt + B` | 開啟筆刷製作工坊（一鍵抓取剪貼簿/選區圖形製作 SAI2 筆刷工具） |
| `Ctrl + Alt + K` | 開啟速寫練習參考視窗 |
| `F10` | 暫停 / 恢復縮時錄影 |
| `Enter` (液化中) | 套用液化結果並貼回 SAI2 |
| `Esc` (液化中) | 取消液化並關閉編輯器 |
| `[` / `]` | 縮小 / 放大筆刷尺寸 |
| `M` (液化中) | 切換液化網格顯示 |
| `Ctrl + Z` | 復原 (Undo) |
| `Ctrl + Y` | 重做 (Redo) |
| `Ctrl + 滾輪` | 縮放畫布 |
| `空白鍵 + 拖曳` | 平移畫布 |
