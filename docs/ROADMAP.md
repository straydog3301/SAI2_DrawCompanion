### 1.1 實機驗收
到目前為止都是自動測試與截圖檢查，下列項目要在真的環境確認一次：

| 項目 | 要確認的事 |
|---|---|
| 打包後的 exe | 線上圖庫（https）、縮時錄影與 ffmpeg 合成、在 SAI2 開檔、開機啟動（登錄檔指向 exe）、單一實例交接 |
| Windows 11 外框 | 主題色的視窗外框與標題列（截圖拍不到） |
| 顯示縮放 | 100%、125%、150%、200%，以及多螢幕不同縮放時寵物、泡泡、小窗的位置 |
| 淺色主題 | 五種主色逐頁看一次 |
| 自訂泡泡 | 圈選文字範圍的拖曳手感、實際跳出的泡泡 |
| 與 1.x 並存 | 1.x 開啟／關閉時 2.0 暫停與恢復、`watcher.pyw` 自動開 1.x 的情境 |

做法：照 [RELEASE_CHECKLIST.md](RELEASE_CHECKLIST.md) 跑；發現的問題補成自動測試。

### 1.2 已知問題
- ~~**作品名稱記錄方式**~~（已處理）：紀錄的 key 維持與 1.x 相同；清單只顯示檔名，自動分組改為跳過使用者名稱與「桌面」「文件」這一層
- ~~**`tests/core/test_brush_assets.py` 時好時壞**~~（已修正）：備份資料夾名稱加上遞增序號，同一毫秒內的作業也能依建立順序排序

### 1.3 啟動速度
單一 exe 冷啟動約 4.5 秒（每次要先解壓）。開機自動啟動時影響不大，但手動開啟會覺得慢。選項：
- **資料夾版（onedir）**：啟動快，但發布物是一個資料夾；要讓 exe 仍能放在 1.x 旁邊共用紀錄
- **啟動畫面**：PyInstaller 的 splash，先讓使用者知道程式在開
- **延後載入**：主視窗、成長頁、課程資料等用到才載入

先量測（冷啟動、熱啟動、各階段耗時）再決定。

## 2. 2.0.x：穩定與維護

### 2.1 程式結構
- `ui2/settings_pages.py`（約 1200 行）、`ui2/ref_window.py`（約 1200 行）拆成數個檔案
- 規則頁、快捷面板設定目前是「整頁重建」，造成過捲動位置跳回最上面的問題。改成只更新變動的那一列
- 清除版面的寫法有好幾種（`_clear`、`_drop`、`setParent(None)`），統一成一個共用函式

### 2.2 測試與自動化
- 介面測試改用 pytest-qt（§17 的原訂做法），減少自寫的事件迴圈與等待
- GitHub Actions（Windows）：每次推送跑 `tests/run_tests.py --core`；介面測試看執行時間再決定
- 時好時壞的測試要找出原因修掉，不靠重跑

### 2.3 錯誤回報與資料安全
- ~~未處理的例外寫進 `APP_DIR` 的記錄檔；設定頁加「匯出診斷資訊」~~（已完成：`core/diagnostics.py`）
- 確認 `sai2_draw_time.json`、`daily_quests.json` 的定期備份與損毀時的還原流程，缺的補上

### 2.4 效能
- 量測待機時的 CPU 與記憶體：每秒的追蹤、寵物動畫、大尺寸自訂角色的影格快取
- 自訂角色影格太大時自動縮小快取，或提醒使用者

### 2.5 無障礙後續
- 用 Windows 朗讀程式（Narrator）或 NVDA 實際操作一輪
- Windows 高對比模式、系統文字放大的支援

### 3.1 練習體驗（實際使用回饋，2026-10-23）

速寫與反覆練習對新手太難、不知道怎麼開始。依建議順序：

| # | 項目 | 內容 | 已有的基礎 |
|---|---|---|---|
| 1 | ~~速寫倒數改用實際動筆秒數~~（已完成） | 與研究任務相同：SAI2 上有下筆才倒數，離開畫圖時暫停；設定可選「實際時間」或「動筆時間」 | 研究任務的動筆計時（`core/companion.py`、`DrawTracker`） |
| 2 | ~~速寫自動建立畫布~~（已完成） | 一輪一張畫布，預設 A4 橫向（300 dpi），尺寸在 設定 → 參考圖來源 → 練習畫布 | 研究的「畫布」按鈕（`core/study_tools.py` 的 `create_canvas`） |
| 3 | 反覆練習的參考與說明 | 每個反覆練習範本加上：目的、做法步驟、示範圖、常見錯誤、完成標準；在參考小窗顯示（與研究課程相同的版面） | 課程資料格式（`core/study_lessons.py`） |
| 4 | 新手難度 | 第一次使用時問程度（新手／有基礎／熟練），決定速寫的間隔與張數；新手從 2～5 分鐘、5 張開始。依完成率自動調整（常常沒畫完就降低、輕鬆完成就提高） | 「30 秒調整你的練習」卡片、`core/onboarding.py` |
| 5 | 速寫課程 | 課程頁加入「速寫」路徑：動態線 → 剪影 → 基本結構 → 手腳與頭部 → 長時間速寫。每堂課指定題目、間隔、張數與這堂課只看的重點，用參考小窗的速寫模式上課 | 7 條研究路徑的課程結構與進度 |
| 6 | 自訂課程與分享 | 使用者用編輯器建立自己的課程（步驟、時間、參考圖來源），匯出成檔案分享；匯入時驗證格式、不執行任何程式。社群分享的地方（GitHub、Discord 或專屬頁面）另外決定 | 角色包、設定檔的匯出／匯入與安全檢查（`core/pet_pack.py`、`core/backup.py`） |
