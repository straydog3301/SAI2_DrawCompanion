# 每日任務與繪圖技能體系（v1.7.0 規劃）

激勵使用者每天練習：主畫面每日出現 1~3 項依「平衡課表」排出的任務，可一鍵「前往」開始、達標後打卡，練習時間累積到獨立的**繪圖技能**，形成可回顧的成長紀錄。

## 1. 兩個維度：技能 × 練習方式

**技能（練什麼）**——任務以「技能權重」標記，一個任務可同時練多項技能（例：色彩臨摹 = 色彩 0.7 + 明暗 0.3）。

| id | 技能 | 子主題 |
|---|---|---|
| `perspective` | 📐 透視 | 一/二/三點透視、圓與橢圓、室內場景、人物置入 |
| `form` | 🧊 形體結構 | 基本幾何體、穿插與結構線、物體簡化 |
| `figure` | 🧍 人體與動態 | 姿勢速寫、解剖、手腳、臉部、皺褶 |
| `value` | ◐ 明暗光影 | 明度分級、光源與投影、反光 |
| `color` | 🎨 色彩 | 色彩臨摹、色彩關係、氛圍光色、限色 |
| `composition` | 🖼️ 構成 | 縮圖構圖、視線引導、黑白灰配置 |
| `line` | ✒️ 線條筆觸 | 控線、線條輕重、筆刷運用 |
| `rendering` | 🔍 質感描繪 | 金屬、布料、毛髮、自然物 |

使用者可自建技能（之後的任務管理視窗）。

**練習方式（怎麼練）**——決定「前往」做什麼、進度如何判定：

| mode | 練習方式 | 進度單位 | 判定 | 前往 |
|---|---|---|---|---|
| `sketch` | ⚡ 計時速寫 | 張 | 速寫視窗倒數**自然歸零**才算一張（不限時：停留 ≥30 秒） | 開速寫視窗並帶入題目、間隔 |
| `study` | 🖌️ 臨摹研究 | 分鐘 | 研究進行中在 SAI2 的**實際動筆時間** | 開始研究計時並切到 SAI2（第 2 階段加參考圖工具） |
| `drill` | 🔁 反覆練習 | 個 | 自行回報次數 | 輸入本次完成數 |
| `thumbnail` | 🗂️ 縮圖構成 | 張 | 自行回報張數 | 輸入本次完成數 |
| `draw_time` | ⏱️ 創作時長 | 分鐘 | 當日 SAI2 動筆時間 | 切到 SAI2 |

## 2. 每日課表（平衡抽選）

- **任務日**以「換日時間」切分（預設 04:00，凌晨 2 點仍算前一天）。
- 每天第一次啟動或換日時產生一次並存檔，重開程式不變。
- 數量在 `count_min`~`count_max`（預設 1~3）間隨機；所有任務的預估時間合計不超過**每日時間預算**（預設 60 分）。
- 課表結構：2 項以上時第一項優先排**熱身**（≤15 分的速寫），其餘為主練。
- 權重 = 範本權重 × **冷落加權**（技能越久沒練越高，最多 ×3）× **本週主修**（×2）× 與昨天相同範本 ×0.3。
- 創作時長一天最多一項。
- 🔄 **換一個**：每日次數有限（預設 1）；➕ **加入今日**：手動加入不受數量與預算限制。
- 今日任務保存範本參數的快照，事後修改或停用範本不影響當天。

## 3. 狀態與打卡

`active`（進行中）→ `ready`（達標可打卡）→ `done`（已打卡）；換日時未打卡者 → `expired`。

- 未達標也可**自行回報打卡**（紀錄標示 `self_reported`），支援在程式外的練習。
- 打卡可留心得。第 4 階段加入打卡快照與自評量表。
- 🔥 連續天數：任務日至少打卡 1 項即延續（+1）；當天尚未打卡不中斷；另記錄歷史最長天數。
- 💤 休息日：每週可請假 `rest_days_per_week` 天（預設 1，週一到週日計），只能設定今天或補請昨天；休息日延續連續天數但不加天數，已打卡的日子不需請假。

## 4. 練習紀錄與技能累積

所有技能數據都由 `practice_log` 即時計算，新增技能或練習方式不需改格式：

- 速寫：每張有效圖即時記錄（秒數 = 間隔），技能取自任務；非任務速寫依題目對應技能（如手部 → 人體）。
- 研究 / 反覆練習 / 縮圖 / 創作時長：打卡或換日過期時記錄實際投入（反覆練習以預估時間 × 完成比例）。
- 技能等級採投入時數里程碑：入門 10h → 基礎 30h → 進階 100h → 熟練 300h → 精通 1000h，並顯示近 30 天投入。

## 6. 臨摹研究：帶目標的課程（第 2 階段）

只記錄作業時間對新手沒有方向，因此每個臨摹研究任務都對應一堂**課程**，附參考圖、單一學習重點、分段步驟與完成檢查。

### 6.1 課程卡（`core/study_lessons.py`）
每堂課包含：技能與等級、**目標**、**本次只專注**（刻意練習：一次只練一件事）、分段步驟（名稱 / 分鐘 / 提示）、常見錯誤、完成檢查、預設開啟的檢查工具、參考來源。

### 6.2 學習路徑與推進
- 每個技能一條由淺到深的路徑（透視、形體、人體、明暗、色彩、構成、質感各 4~5 堂；線條以反覆練習為主）。
- 每日抽到某技能的臨摹研究時，自動排該路徑的**下一課**，任務名稱與預估時間依課程而定。
- 打卡時自評 1~5 分：**≥3 分推進下一課**，否則下次以新參考圖重練同一課；最後一課可反覆練習。
- 進度存於 `lesson_progress`：`{技能: {"index": 0, "passed": [...], "attempts": {課程 id: 次數}}}`。

### 6.3 參考來源（`core/study_refs.py`，依課程設定的順序嘗試）
| 來源 | 用途 | 說明 |
|---|---|---|
| 大都會博物館 Open Access | 名作臨摹 | `v1.1/search`（2026-10-01 起舊版 `v1/search` 已停用）分頁搜尋 → `v1/objects/{id}`；僅取 `isPublicDomain` 且畫家相符的作品 |
| 芝加哥藝術博物館 API | 名作臨摹 | `artworks/search` + `query[term][is_public_domain]=true`；圖片走 IIIF（`/iiif/2/{image_id}/full/843,/0/default.jpg`）；請求帶 `AIC-User-Agent` |
| Unsplash / Pexels | 寫生式研究 | 沿用速寫金鑰，每堂課內建精選關鍵字；沒有金鑰時略過 |
| 本機資料夾 | 自備參考 | 以速寫的本機圖庫為後備 |

兩個美術館的搜尋都是寬鬆比對，結果需以畫家名稱過濾。參考圖快取於 `study_refs_cache/`，並標示作者、作品、年代、來源連結、授權與「為什麼選這張」；可「換一張」或自選圖檔。

### 6.4 研究視窗
- 課程卡：目標、本次專注、分段步驟（依**實際動筆時間**推進，換階段時提示）、常見錯誤、完成檢查。
- 檢查工具：水平翻轉、灰階、明度分階（3 / 5 階）、主色擷取（6 色）、構圖輔助線（三分 / 九宮格 / 對角線）。
- **比對模式**：擷取 SAI2 畫布（自動裁掉工作區灰底，可拖曳框選）與參考圖並排，翻轉 / 灰階 / 明度分階同時套用到兩邊。
- 可置頂浮在 SAI2 上；完成後於視窗內直接打卡（含自評）。
