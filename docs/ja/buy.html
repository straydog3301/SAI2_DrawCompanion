お支払い後の手順：

  1. Gumroad からライセンスキーがメールで届きます。領収ページや Gumroad の Library でも確認できます。
  2. SAI2 を一度起動します（SAI のライセンス証書がインストールされている必要があります）。
  3. DrawCompanion の「Mod」ページでキーを貼り付けて「アクティベート」を押し、SAI2 を再起動します。

1 つのキーは 1 つの SAI ライセンスに紐づきます。PC の買い替えや再インストール後は、同じキーでもう一度有効化してください。購入により利用規約・プライバシーポリシー・返金ポリシーに同意したものとみなされます。

受信トレイ（迷惑メールフォルダも）で Gumroad の領収メールを探してください。キーはそのメールに記載されています。または、購入時のメールアドレスで Gumroad Library にログインし、この商品を開いてください。それでも見つからない場合は、購入時のメールアドレスを添えて drawcompanion@gmail.com までご連絡ください。
