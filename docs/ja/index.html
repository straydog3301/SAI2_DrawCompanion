SAI2 のデスクトップ相棒

DrawCompanion は PaintTool SAI2 のそばで静かに寄り添います。作品ごとの作画時間を自動で記録し、毎日の練習を組み立て、クロッキーや模写の参考画像はキャンバスを邪魔しない小さなウィンドウで表示します。

2.0 をダウンロード（zip） はじめかた

Windows 10／11 · インストール不要、解凍するだけ · 以降はアプリ内でワンクリック更新

起動しておくだけで記録

SAI2 で描いているファイルを検出し、実際に筆を動かしている時間だけを数えます。開始ボタンも、止め忘れもありません。

今日やる練習がわかる

伸ばしたいスキルに合わせてクロッキー、模写、反復練習を組み立てます。終わったらチェックイン。連続日数とスキルの成長がひと目でわかります。

画面を占領しない

ふだんは小さなペットが一匹いるだけ。参考画像はマウスが通り抜ける小窓なので、モニター 1 枚でも見ながら描けます。

2.0 の新機能

1.x から全面的に作り直し、新しく加わった機能です

講座を自分で作る

手順を書き、参考画像を置き、合格基準と採点項目を決め、自分の作品で AI 講評を調整。.dccourse として書き出して友達に渡せます。

コミュニティ講座ライブラリ

講座を公開したり、ほかの人の講座をワンクリックで追加したり。作者はいつでも更新・公開停止でき、共有コードで直接渡すこともできます。

自動更新

新しいバージョンが出るとペットが教えてくれます。「更新して再起動」を押すだけ。記録と設定はそのまま、更新に問題があれば自動で前のバージョンに戻ります。

機能一覧

2.0 の実際の画面（サンプルデータ、中国語表示）です。アプリは日本語・英語でも使えます。

デスクトップペット × クイックパネル

モモをクリックすれば、よく使う機能がそろっています

起動するとデスクトップにはモモだけが表示され、好きな場所にドラッグできます。クリックするとクイックパネルが開きます：

  • 今日の進捗：今日描いた分数と連続日数
  • デイリータスク：開始、続き、チェックイン
  • 最近開いた作品：サムネイルをクリックすると SAI2 で直接開きます
  • ショートカットボタン：クロッキー、模写、スナップショット、タイムラプス録画など。自由に入れ替えられます

モモは SAI2 の状態に合わせて動きを変え、描きすぎると休憩をすすめてくれます。ペットの下には今回の作画時間と録画スイッチが表示されます。

参考ウィンドウ

クロッキーも模写も小さなウィンドウで

  • クロッキー：ローカルのフォルダやオンライン画像ライブラリから自動で切り替え。描いている間だけカウントダウンし、参考画像を見ているときは一時停止します
  • キャンバスを自動作成：1 セットごとに A4 キャンバスを SAI2 で開きます
  • 模写スタディ：7 つの学習パス。各レッスンに段階的な手順、ポイント、完了チェックがあり、自作やコミュニティの講座も追加できます
  • クリックスルーモード：半透明でマウスが通り抜ける小窓をキャンバスに重ねて、なぞるように描けます
  • 押して比較：ショートカットキーを押している間、自分のキャンバスに参考画像を重ねて比べます
  • AI 講評（オフにできます）：講座のチェックイン時に自分の AI キーで採点と短い講評をつけ、次のレッスンに進むか判断します（無料枠のある Google AI Studio がおすすめ）
  • グレースケール、明度段階、構図ガイドなどのチェックツール
フローティングメモ × 参照ビューア

よく使う設定や参考画像を手元に

  • フローティングメモ：複数のタブにカラーパレット、ブラシ設定、キャラクター設定をメモ。``` で囲んだ部分はワンクリックでコピー
  • 閲覧／編集モード。「完了」か Ctrl+S で保存。見出しは折りたたみ可能で、目次からジャンプできます
  • 編集中は Ctrl+V でスクリーンショットを貼り付け。画像をクリックで拡大・クリップボードにコピー。最前面表示も切り替えられます
  • 参照ビューア：講座以外でも参考画像を 1 枚表示（開く、貼り付け、ドラッグ）。拡大縮小・移動、スポイト、グレースケール、構図ガイド、クリックスルー、押して比較
今日

今日なにを練習するか、ひと目でわかる

メインウィンドウの「今日」ページに、今日の作画時間、デイリータスク、今週の作画グラフ、スキルの動きをまとめ、しばらく練習していないスキルも知らせます。

  • タスクは毎日の練習時間と伸ばしたいスキルから組み立てられ、入れ替えや手動追加もできます
  • 毎週お休みの日を設定でき、連続日数は途切れません
  • 初回は 30 秒で練習量を調整。3 日後に実際に描いた時間をもとにもう一度提案します
成長

毎日の積み重ねが目に見える

  • 練習カレンダー：チェックインが多い日ほど色が濃く、日付をクリックするとその日の内容が見られます
  • 作画時間の統計：週、月、半年、1 年
  • スキルカード：スキルごとの累計時間とレベル
  • チェックインのたびにキャンバスのスナップショットを自動保存。あとから上達を振り返れます
作品

作品ごとの作画時間とサムネイル

  • 保存時や手を止めたときにサムネイルを自動取得し、一覧でそのまま見られます
  • 作画時間、起動時間、作画効率、描いた回数
  • スキルタグ：この作品の時間をどのスキルに加算するか
  • 「名前を付けて保存」のあとに 2 つの記録を 1 つにまとめられます。タイムラプス動画もここにあります
カスタマイズ

自分好みの姿に

  • オリジナルキャラクター：自分で描いたキャラクターを使い、状態ごとに別のアニメーションを設定（PNG／GIF／APNG／WebP）
  • 最大 5 匹のペットが交代で登場、カスタム動作（手を振る、伸びをする…）、スプライトシートの自動分割
  • 吹き出しの見た目：好きな画像を吹き出しにして文字の範囲を指定。四隅は伸びません。ペットごとに設定も可能
  • 「もし…なら…」ルール：例えば「50 分描き続けた → モモが休憩をすすめて動作する」「モモをドラッグ → 移動中ずっと指定の動作、離したらひとこと」。ペットごとの専用ルールも作れます
  • テーマカラーとライト／ダーク、クイックパネルの項目とボタン、ショートカットキー
  • 文字サイズ 75%〜150%
  • 設定やキャラクターを書き出して共有。キャラクターをコミュニティペットライブラリに公開したり、ほかの人のキャラクターをワンクリックで追加したりできます

はじめかた

インストール不要。解凍したらあと 3 ステップ

ダウンロードして解凍

こちらから DrawCompanion2.zip（約 36 MB）をダウンロードし、右クリック →「すべて展開」で D:\DrawCompanion などのフォルダに解凍します。

ファイルはまとめて

フォルダには DrawCompanion2.exe と _internal フォルダがあり、2 つは同じ場所に置いてください。記録、設定、サムネイル、動画もここに保存されるので、移動するときはフォルダごと移動します。

DrawCompanion2.exe をダブルクリック

デスクトップにモモが出てきたら完了です。SAI2 を開いて描き始めましょう。ほかの設定は初期値があり、必要なときに案内します。

動作環境

  • Windows 10 または 11（64 ビット）
  • PaintTool SAI Ver.2
  • タイムラプス録画を動画にするときだけ ffmpeg（PATH に追加）
  • オンライン画像ライブラリ（Unsplash／Pexels）は無料の API キーが必要。なくてもローカルフォルダの参考画像は使えます

初回起動時

  • 「Windows によって PC が保護されました」と表示されることがあります。「詳細情報 → 実行」を押してください（説明）
  • zip の中から直接実行せず、先に解凍してください。exe だけを取り出すのも NG です
  • 同時に起動できるのは 1 つだけで、二重起動はしません

初回起動で「Windows によって PC が保護されました」と出たら？

よくあることです。2 回クリックすれば続けられ、次回からは表示されません。

表示される理由

これは Windows に組み込まれた Microsoft Defender SmartScreen です。ダウンロード数が少なく、デジタル署名のないプログラムを止めます。DrawCompanion は個人開発のツールで、年間数百ドルかかるコード署名証明書を持っておらず、ダウンロード数もまだ少ないため、Windows がまだ「知らない」状態です。ウイルスが見つかったわけではなく、画面にも脅威は表示されていません。

安心して使える理由

  • ダウンロードは GitHub Releases で配布。アプリの自動更新は開発者の署名を確認し、ファイルが差し替えられていればインストールしません
  • SAI2 のウィンドウタイトルから描いているファイルを判断するだけで、SAI2 の設定や既存の作品ファイルは変更しません
  • 管理者権限は不要で、記録はプログラムのフォルダにだけ保存されます
  • このページのダウンロードボタンからのみ入手してください
  • それでも心配なら、zip を VirusTotal にアップロードして数十種類のウイルス対策ソフトで検査できます

別の方法：解凍する前に zip を右クリック →「プロパティ」→ 下の「許可する」にチェック → OK。解凍したプログラムでは表示されなくなります。会社や学校の PC で「実行」ボタンがない場合は、管理者に相談してください。

よくある質問

アプリは日本語で使えますか？

はい。アプリと、SAI2 に追加されるメニューやダイアログは日本語・英語・繁体字中国語に対応しています。初期設定では Windows の表示言語に合わせ、「設定 › 一般 › 言語」で変更できます（再起動後に反映）。

Photoshop や CLIP STUDIO PAINT でも使えますか？

使えます（2.2 から）。「設定 › 一般 › お絵描きソフト」で切り替えると、作画時間、デイリーチェックイン、作品の記録、キャンバスの取得がそのソフトに合わせて動きます。Photoshop の取得には画面がほかのウィンドウで隠れていないこと、CLIP STUDIO PAINT は複数のキャンバスを開いているときは最後に開いたものが対象で、取得画像は最後に保存した状態です。タイムラプス録画と Mod は今のところ SAI2 のみ対応です。

なぜ exe 1 つではなく zip なのですか？

フォルダ版は起動のたびにプログラム全体を一時フォルダに展開しないので、起動が速く、ウイルス対策ソフトに誤検知されにくくなります。自動更新もこのフォルダを直接入れ替えます。DrawCompanion2.exe を実行し、_internal フォルダは削除・移動しないでください。

更新後に問題が起きたら？

新しいバージョンが 3 回続けて正常に起動しなかった場合、自動で前のバージョンに戻ります。「設定 › 一般 › 更新」の「前のバージョンに戻す」でも戻せます。前のバージョンはフォルダ内の _previous に保存されています。

Python などのインストールは必要ですか？

不要です。解凍したフォルダに必要なものがすべて入っているので、DrawCompanion2.exe を実行するだけです。タイムラプス録画を動画にするときだけ ffmpeg が別途必要です。

作品や記録がアップロードされることはありますか？

ありません。記録、サムネイル、設定はすべてあなたの PC（プログラムのフォルダ）に保存されます。通信するのは、参考画像の取得（メトロポリタン美術館、シカゴ美術館、Unsplash、Pexels）、更新の確認、コミュニティライブラリの閲覧、ライセンスのアクティベート、そして AI 講評をオンにしたときだけです。アップロードされるのは自分で公開した講座とキャラクターだけで、利用状況は収集しません。

クロッキーのカウントダウンが動きません

初期設定では「描いているときだけカウントダウン」です。SAI2 の保存済みキャンバスに描くと進み、参考画像を見ている間は止まります。開始時にキャンバスは自動で作成されます。常にカウントダウンしたい場合は、参考ウィンドウの設定でオフにしてください。

ペットが作業の邪魔になるときは？

モモは好きな場所にドラッグでき、描いている間は自動で半透明になります。クイックパネルの「30 分隠す」で一時的にしまえて、タスクトレイのアイコンからいつでも呼び戻せます。

自分で描いたキャラクターにできますか？

できます。「設定 → コンパニオン」でラインナップの「＋」を押し、状態ごとに画像を指定してください。512×512 の透過 APNG か WebP がおすすめで、スプライトシートも使えます。作ったキャラクターパックは書き出して共有したり、コミュニティペットライブラリに公開したりできます。
