# 2.0 介面規劃（草案 v2：寵物＋參考小窗）

> 狀態：階段 0～5 已完成（版本 2.0.0，發布前實機測試中，見 [RELEASE_CHECKLIST.md](RELEASE_CHECKLIST.md)）。核心邏輯沿用 `core/`（見 [ARCHITECTURE.md](ARCHITECTURE.md)），2.0 只重寫介面層。
> 視覺示意圖：Design 畫布「DrawCompanion 2.0 介面示意」（「2.0 改版：寵物＋小窗」頁；「初版」頁的今日頁 A 為控制中心的版面）。

## 1. 為什麼要重做介面

1.x 的介面是功能一個個加上去的，累積了這些問題：

| 問題 | 現況（v1.7.0） |
|---|---|
| 視窗散落 | 7 個主要視窗（主視窗、設定、速寫、臨摹研究、筆刷工坊、液化、任務管理）＋約 10 個臨時對話框 |
| 頻繁打斷 | 54 處系統訊息框 / 輸入框，畫圖時跳出來搶焦點 |
| 占畫面 | 速寫與研究視窗是大視窗，單螢幕時會蓋住 SAI2 的畫布，沒辦法邊看邊畫 |
| 主視窗太擠 | 540 寬的直式視窗塞了計時、任務、錄影、檔案清單與 8 顆按鈕 |
| 縮放與版面 | Tk 只能靠手動換算撐住高縮放；工具列無法換行 |
| 樣式不一致 | 各視窗各有一套顏色與按鈕；表情符號當圖示 |
| 客製化有限 | 只有少數開關，快捷鍵、版面、通知都不能自己調 |
| 重複啟動 | 監視器與手動啟動會各開一份，見 §10 |
| 開檔介面不同 | 從檔案開啟 SAI2 與直接開 sai2.exe 的介面不一樣，見 §11 |

## 2. 設計目標

1. **畫圖時畫面上只有寵物和參考小窗**：啟動後不開主視窗，只出現桌面寵物；練習時多一個小小的參考窗，都不蓋住畫布。
2. **常用功能一鍵到**：點寵物就有每日任務、最近開啟的檔案、快捷按鈕。
3. **需要時才展開**：參考小窗平常只有圖和一行進度，滑鼠停留才浮出工具，點了才展開步驟。
4. **高自由度客製化**：角色、快捷面板、快捷按鈕、規則、快捷鍵、主題都能自己改，設定可整套匯出 / 匯入。
5. **不打擾**：確認與提醒改成寵物泡泡或視窗內的側滑面板，不用系統對話框搶焦點。
6. **穩定的程式行為**：同時只會有一份在執行；開檔一律走同一條流程。

## 3. 技術選擇：PySide6（Qt 6）

**已決定採用 PySide6**，依本專案的需求比較：

| 需求 | PySide6 | 其他選項的問題 |
|---|---|---|
| 沿用 `core/`（Python） | 直接匯入 | Electron / Tauri 要另寫 Python 後端與通訊，`core/` 不能直接呼叫 |
| 逐像素透明、可拖曳的寵物視窗 | 內建（無邊框＋透明背景＋遮罩） | Tk 只能做單一透明色，邊緣會有色邊 |
| 參考小窗滑鼠穿透、強制置頂 | 內建旗標，另可呼叫 Win32 | wxPython 要大量自行處理 |
| 動畫影格播放、圖片縮放 | 內建繪圖與計時器，品質好 | Tk 每格都要轉圖，大尺寸會卡 |
| 高 DPI、版面自動伸縮、主題 | 內建樣式表與版面配置 | Tk 需手動換算（1.x 的 `ui_kit`） |
| 單一實例通道、系統匣、全域快捷鍵 | `QLocalServer`、`QSystemTrayIcon`；快捷鍵沿用 Win32 | — |
| 授權 | LGPL，可免費發布 | — |

代價：exe 變大（預估 60～100 MB，可排除用不到的模組壓縮）、打包設定要重做、介面程式要重寫（本來就要重寫）。

開工前先做**技術驗證**（各 1～2 天，任一項做不到就重新評估）：
1. **寵物視窗**：逐像素透明、無邊框、強制置頂、可自由拖曳、點擊與拖曳能分辨；被 SAI2 全螢幕蓋住時能自我修復；動畫 60 張以內不卡
2. **參考小窗穿透模式**：視窗半透明且滑鼠事件穿透到 SAI2（`WS_EX_TRANSPARENT` / `Qt.WindowTransparentForInput`），再按快捷鍵能恢復
3. **單一實例**：具名 Mutex＋本機通道（`QLocalServer`），第二份啟動時把參數轉給第一份後立即結束
4. **SAI2 開檔流程**：SAI2 已開啟時把檔案交給現有的 SAI2；未開啟時先開 sai2.exe、等主視窗就緒再開檔（見 §11）
5. 全域快捷鍵與前景視窗監聽（沿用 Win32 呼叫）
6. 擷取 SAI2 畫布，按住快捷鍵時疊在參考小窗上比對

## 5. 桌面寵物

### 5.1 行為（參考 Bongo Cat）
- **自由拖曳到任何位置**，放開後記住位置（依螢幕分別記錄；螢幕拔掉或解析度改變時自動拉回可見範圍）；可選「貼齊螢幕邊緣」
- 左鍵點擊（移動小於 4 px 才算點擊）→ 快捷面板，面板自動開在寵物有空間的那一側
- 右鍵 → 選單：控制中心、設定、暫時隱藏 30 分、鎖定位置、結束
- 可調大小（48～256 px）、透明度；可選「動筆時變半透明」「筆或滑鼠靠近時自動避開」「其他程式全螢幕時隱藏」
- 寵物視窗只有角色本身的不透明像素能接收滑鼠，透明區域點下去會落到下面的程式

### 5.2 狀態
| 狀態 | 何時出現（預設，可在規則中修改） | 播放 |
|---|---|---|
| 待命 `idle` | SAI2 開著、沒動筆 | 循環 |
| 一起畫 `drawing` | 偵測到動筆 | 循環 |
| 歡呼 `cheer` | 任務打卡、升級、連續天數里程碑 | 播一次後回到前一個狀態 |
| 休息 `rest` | 連續動筆 50 分 | 循環 |
| 提醒 `remind` | 畫布未存檔、連續紀錄快中斷 | 播一次 |
| 睡覺 `sleep` | 請假日、夜間（可設定） | 循環 |
| 未連結 `offline` | 程式已啟動但 SAI2 未開啟 | 循環 |

- 只要程式啟動寵物就會出現，不因 SAI2 未開啟而隱藏
- 「未連結」預設沿用「睡覺」的動畫；使用者可另外指定圖檔，方便一眼看出有沒有連上 SAI2
- 沒設定圖檔的狀態依序沿用：未連結 → 睡覺 → 待命，所以最少只要一張圖就能用

### 5.3 圖檔規格（自訂角色）
| 項目 | 規格 |
|---|---|
| 支援格式 | **PNG（靜態）、GIF、APNG、動態 WebP**，以及「一張橫排的精靈圖 PNG」 |
| 建議格式 | **APNG 或 WebP**：完整半透明邊緣、全彩。GIF 只有全透明 / 不透明兩種，手繪角色的邊緣會有鋸齒或白邊，且只有 256 色 |
| 畫布尺寸 | 建議正方形 512×512（最小 128×128）；同一角色各狀態的尺寸一致 |
| 背景 | 透明 |
| 對齊點 | 預設底部置中（角色腳底）；可在說明檔改 |
| 影格 | 每個狀態 120 張以內；精靈圖需註明格數 |
| 速度 | GIF / APNG / WebP 用檔案內的每格時間；精靈圖在說明檔設定 fps（建議 8～24） |
| 檔案大小 | 每個狀態 5 MB 以內 |

實作：一律用 Pillow 解出影格（GIF / APNG / WebP 都支援），轉成 Qt 圖片後自己播放，避免依賴 Qt 各格式外掛的差異。載入時依顯示大小預先縮放，記憶體不隨原圖尺寸暴增。

### 5.4 角色包格式
一個資料夾（或同內容的 `.zip`），放在 `APP_DIR/pets/<角色名>/`：
```
pets/my_cat/
├─ pet.json
├─ idle.apng
├─ drawing.png        # 精靈圖
└─ cheer.webp
```
```json
{
  "name": "我的貓",
  "author": "",
  "version": 1,
  "anchor": "bottom-center",
  "states": {
    "idle":    {"file": "idle.apng", "loop": true},
    "drawing": {"file": "drawing.png", "frames": 8, "fps": 12, "loop": true},
    "cheer":   {"file": "cheer.webp", "loop": false}
  }
}
```
寵物工作室（設定 → 寵物）可以直接選圖檔建立角色包，不需要手寫 `pet.json`。預設角色只做示意，實際美術由作者自行繪製後放入。

## 6. 快捷面板（點寵物）
由上到下（區塊可在設定中排序、開關）：
1. 今日進度環與連續天數
2. 每日任務：最多 3 個，可直接「開始 / 繼續」，已完成顯示「已打卡」；「換一個」
3. 最近開啟：4 個檔案縮圖，點了用 §11 的流程在 SAI2 開啟；「全部作品」連到控制中心
4. 快捷按鈕：6 格（預設 速寫、研究、快照、錄影、作品、開啟 SAI2），可放任一工具、開指定檔案或資料夾、執行外部程式、開網址、送出 SAI2 快捷鍵組合
5. 底部：控制中心、設定、隱藏 30 分

面板失去焦點、按 Esc 或再點一次寵物就收起。

## 7. 參考小窗（速寫與研究共用）
| 狀態 | 內容 |
|---|---|
| 平常 | 只有參考圖＋一行進度（例如「2/4 大色塊 · 7:12」），預設寬約 240 px |
| 滑鼠停留 | 上方浮出工具列（翻轉、灰階、明度分階、格線、比對、穿透、透明度、釘選），下方浮出 換一張 / 練習畫布 / 打卡 |
| 點進度列 | 往下展開步驟、學習重點、常見錯誤、完成檢查 |
| 速寫 | 倒數圈疊在圖的角落、「第 10 / 15 張」；快捷鍵切下一張 / 暫停 |
| 比對 | 按住快捷鍵時疊上 SAI2 畫布擷取（並排 / 疊圖 / 滑桿），放開回到參考圖 |
| 縮成膠囊 | 只剩「階段名＋剩餘時間」貼在寵物旁 |
| 穿透模式 | 半透明且滑鼠點擊穿透到 SAI2，可把參考圖疊在畫布上描形；再按快捷鍵恢復 |

打卡在小窗內側滑出「自評＋心得＋畫布快照」，不跳系統對話框。小窗的位置、大小、透明度依速寫 / 研究分別記住。

## 8. 控制中心
沿用初版示意圖的「今日頁 A」：左側欄（寬版 ≥ 900 顯示文字，窄版收成圖示列）＋內容兩欄。今日、課程、成長、作品各頁內容同初版規劃：
- **今日**：今日任務（主角）、SAI2 狀態卡、本週長條、技能動態
- **課程**：學習路徑進度、課程詳情（目標、重點、分段步驟、推薦參考作品、歷次打卡快照），可預習與手動選課
- **成長**：連續天數、月曆熱度圖（點日期顯示當日明細）、技能卡、統計圖表
- **作品**：檔案卡片 / 清單、檔案詳情（時間走勢、縮時影片、快照、技能標籤）

關閉控制中心只是隱藏，程式與寵物繼續執行；結束程式從寵物右鍵選單或系統匣。

## 10. 程式啟動與單一實例（修正 1.x 重複開啟）

**1.x 的原因**
- `watcher.pyw` 只記得「自己開的那一份」，使用者先手動開了程式，監視器偵測到 SAI2 還是會再開一份；主程式本身沒有防止重複執行
- 監視器以「行程名稱包含 `sai`」判斷 SAI2，條件過寬，其他名稱含 `sai` 的程式也會觸發；而且只要同時有多個監視器在跑（開機捷徑＋手動執行）就會各開一份

**2.0 的做法**
1. **單一實例**：啟動時取得具名 Mutex（例如 `Local\SAI2DrawCompanion`）。取得失敗代表已有一份在執行 → 透過本機通道把參數（例如要開的檔案、`--show`）交給第一份，第二份立刻結束。第一份收到後把寵物 / 控制中心帶到前景
2. **取消獨立監視器**：開機啟動改為直接啟動主程式的背景模式（`--background`），由主程式自己監看 SAI2；SAI2 未開啟時寵物顯示「未連結」狀態，不再有第二個行程負責「開程式」
3. **精確辨識 SAI2**：行程名稱完全比對（`sai2.exe` 等清單＋設定中的執行檔路徑），再確認視窗類別 / 標題；不用子字串比對
4. 舊版的開機捷徑（`SAI2_DrawCompanion_Watcher.lnk`）在啟動時偵測，由寵物泡泡提示一鍵移除（只提示一次）

## 11. 在 SAI2 開啟檔案的流程（修正介面不一致）

**1.x 的做法**：直接執行 `sai2.exe <檔案>`，找不到執行檔就用 Windows 檔案關聯開啟。SAI2 未開啟時，帶檔案參數啟動的 SAI2 介面與直接開 sai2.exe 不同。

**2.0 統一流程**（快捷面板最近開啟、作品頁、練習畫布、規則動作都走這裡）：
1. 檢查 SAI2 是否已在執行（§10 第 3 點的辨識方式）
2. **未執行** → 先單獨啟動 `sai2.exe`（不帶參數），等主視窗出現且可接受輸入（`WaitForInputIdle`＋找到主視窗，逾時 30 秒）
3. **已執行（或第 2 步完成）** → 把檔案交給現有的 SAI2 開啟，並把 SAI2 帶到前景
4. 確認視窗標題出現該檔名；逾時則寵物泡泡提示「開檔失敗」並提供「改用檔案關聯開啟」
5. 開啟期間寵物顯示讀取中，避免使用者連點造成重複開檔

「交給現有的 SAI2」已在階段 0 實測（見 `spikes/v2_stage0/README.md`）：對主視窗送出拖放檔案訊息與再次執行 `sai2.exe <檔案>` 都會開在既有視窗、不會多出第二個 SAI2；採用拖放方式（不需另開行程），實作在 `core/sai2_launcher.py`。SAI2 執行檔路徑在偵測到 SAI2 執行時自動記下並存入設定，之後不再每次列舉行程猜測；從沒偵測過又需要開檔時，才請使用者指定（見 §16）。

## 12. 暫緩的功能：筆刷工坊、液化

- **2.0 第一版不提供**筆刷工坊（`brush_studio.py`、`core/brush_assets.py`）與液化（`liquify_helper.py`、`main.py` 內的液化熱鍵）
- 這兩個功能在 1.x 仍有缺陷，**不能直接移植**；現有程式碼只作為重新開發時的參考（SAI2 設定檔格式、筆刷素材轉換、剪貼簿取圖貼回的步驟）
- 大部分功能轉換完成並發布 2.0 後，再以新框架重新設計與開發（2.x）
- 2.0 期間仍需要這兩個功能的使用者，繼續使用 1.x
- `core/brush_assets.py` 的待寫入佇列在 2.0 不啟用，避免與 1.x 同時改寫 SAI2 設定檔

## 16. 不需要先設定：用到時才提醒

不做必經的首次啟動精靈，裝好就能用；每項設定都有可用的預設值，真的需要時才由寵物泡泡或當下的畫面提醒，並附「現在設定 / 以後再說」。

| 項目 | 預設（不設定也能用） | 何時提醒 |
|---|---|---|
| SAI2 執行檔路徑 | SAI2 執行時自動偵測並記下 | 從沒偵測過、又要在 SAI2 開檔時 |
| Unsplash / Pexels API 金鑰 | 速寫用本機資料夾或美術館公有領域圖源 | 使用者選了這兩個圖源、或第一次開速寫且沒有其他可用圖源時 |
| 本機參考圖資料夾 | 不使用本機圖源 | 選擇本機圖源時 |
| 每日練習時間、本週主修 | 60 分、平衡課表 | 第一次打開快捷面板時以一張可略過的卡片詢問（見下） |
| 縮時錄影輸出資料夾 | `APP_DIR/videos` | 第一次錄影完成時顯示位置，可改 |
| 開機啟動 | 關閉 | 使用 3 天後詢問一次 |
| 舊版開機捷徑 | — | 偵測到時提示移除一次 |

**建議先設定、能讓第一天就順手的兩項**：每日練習時間與想加強的技能。它們決定第一天排出的任務，沒設定時排出來的任務可能太長或不是想練的。做法是第一次點寵物時，快捷面板最上方出現一張「30 秒調整你的練習」卡片（兩個選項＋「略過」），略過後之後也能在設定改；使用 3 天後寵物再依實際練習時間建議調整一次。

## 18. 已決定事項

- 框架採用 PySide6（理由見 §3）
- 啟動時只出現桌面寵物；寵物可自由拖曳，點擊開快捷面板
- 程式啟動寵物就出現；SAI2 未開啟時顯示「未連結」狀態（預設沿用睡覺動畫，可另外指定）
- 不做必經的首次啟動精靈，所有設定都有預設值，需要時才提醒（§16）
- 速寫與研究合併為參考小窗，平常不占畫面
- 控制中心沿用初版今日頁 A（左側欄）
- 自訂角色支援 PNG / GIF / APNG / WebP / 精靈圖，建議 APNG 或 WebP
- 同時只允許一份執行；開檔一律「先確認 SAI2 → 必要時先開 SAI2 → 再開檔」
- 筆刷工坊與液化延到 2.x 重新開發
- 多開與開檔流程的問題在 2.0 修正，1.x 不另外修
- 2.0 首版介面只有繁中；內建資料已改為以 id 對應翻譯表（`core/data_text.py`），之後補英日文不需改資料
- 打包：另外產生 `DrawCompanion2.exe`（`build2.bat`），與 1.x 的 exe 並存、共用同一份紀錄
- 休息提醒與夜間睡覺改由規則處理（寵物設定不再另外提供）
