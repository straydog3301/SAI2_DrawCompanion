2.0 正式版

陪你畫畫的
SAI2 桌面小夥伴

DrawCompanion 會在 PaintTool SAI2 旁邊安靜地陪著你：自動記錄每張作品畫了多久、每天排好練習任務，速寫和臨摹的參考圖用小窗開著，不占你的畫布。

下載 2.0（zip） 怎麼開始

Windows 10／11 · 免安裝，解壓縮就能用 · 之後在程式裡一鍵更新

開著就會記錄

偵測 SAI2 正在畫哪個檔案，只計算真正下筆的時間；不用按開始、也不會忘記按停止。

每天知道要練什麼

依你想練的技能排好速寫、臨摹、反覆練習；完成就打卡，連續天數與技能成長一目了然。

不占你的畫面

平常只有一隻小寵物；參考圖是可以穿透滑鼠的小窗，單螢幕也能一邊看一邊畫。

2.0 新增

從 1.x 全新改寫，這些是以前沒有的

自己做課程

寫步驟、放參考圖、訂通過標準與評分項目，用自己的作品試評、校準 AI 評分，匯出 .dccourse 給朋友。

社群課程庫

把課程上架，也能瀏覽、一鍵加入別人分享的課程；作者可以隨時更新或下架，或用分享碼直接傳給朋友。

自動更新

有新版時寵物會告訴你，按「更新並重新啟動」就完成；紀錄與設定都保留，新版有問題會自動退回上一版。

功能一覽

以下都是 2.0 的實際畫面（範例資料）

桌面寵物 × 快捷面板

點一下墨墨，常用的都在這

啟動後桌面只會出現墨墨，可以拖到任何地方。點一下打開快捷面板：

  • 今日進度：今天畫了幾分鐘、連續幾天
  • 每日任務：開始、繼續、打卡
  • 最近開啟：作品縮圖，點了直接在 SAI2 開啟
  • 快捷按鈕：速寫、臨摹、快照、縮時錄影…可以自己換

墨墨會依 SAI2 的狀態切換動作，畫太久會提醒你休息；寵物下方顯示本次動筆時間與錄影開關。

參考小窗

速寫、臨摹都在小窗裡

  • 速寫：本機圖庫或線上圖庫自動換圖，下筆時才倒數，停筆看參考圖時暫停
  • 自動建立畫布：一輪速寫一張 A4 畫布，直接在 SAI2 開好
  • 臨摹研究：7 條學習路徑，每堂課有分段步驟、重點與完成檢查；也能加入自製或社群課程
  • 穿透模式：小窗半透明、滑鼠點得穿，疊在畫布上照著畫
  • 按住比對：按住快捷鍵，把你的畫布疊上參考圖比較
  • AI 評鑑（可關閉）：課程打卡時用你自己的 AI 金鑰評分與簡評，決定是否進入下一課（推薦 Google AI Studio，有每日免費額度）
  • 灰階、明度分階、構圖線等檢查工具
浮動筆記 × 參照視窗

常用參數、參考圖，隨手放在旁邊

  • 浮動筆記：多個頁籤，記下色票、筆刷參數、角色設定。用 ``` 包起來的內容一鍵複製
  • 閱讀／編輯兩種模式，「完成」或 Ctrl+S 存檔；標題可以收合，也能從目錄跳轉
  • 編輯時 Ctrl+V 貼上截圖，點圖片放大、複製回剪貼簿；可以切換置頂
  • 參照視窗：不在課程中也能放一張參考圖（開檔、貼上或拖進來），縮放平移、吸色、灰階與構圖線、穿透與按住比對
今日

今天要練什麼，一眼就知道

主視窗的「今日」頁整理今天的動筆時間、每日任務、本週動筆長條圖與技能動態，也會提醒你哪些技能太久沒練。

  • 任務依每日練習時間與想加強的技能排出，可以換一個或手動加入
  • 每週可以請假，連續天數不中斷
  • 第一次使用時用 30 秒調整練習份量，3 天後依你實際畫的時間再建議一次
成長

每天的投入都看得到

  • 練習月曆：打卡越多顏色越深，點日期看當天做了什麼
  • 動筆時間統計：週、月、半年、一年
  • 技能卡：各技能累積時數與等級
  • 打卡時自動存一張畫布快照，回頭看自己的進步
作品

每張作品畫了多久，還有縮圖

  • 存檔、停筆時自動擷取作品縮圖，清單直接看得到
  • 動筆時間、開著的時間、動筆效率、畫了幾次
  • 技能標籤：這張畫的時間算進哪些技能
  • 另存新檔後可以把兩個檔案合併成一筆；縮時錄影的影片也在這裡
客製化

換成你自己的樣子

  • 自訂角色：放上自己畫的角色，每個狀態可以有不同動畫（PNG／GIF／APNG／WebP）
  • 最多 5 隻寵物輪流出場、自訂動作（揮手、伸懶腰…）、序列圖自動切割
  • 對話泡泡外觀：用一張圖當泡泡，圈出文字範圍，四角不變形；每隻寵物也可以有自己的
  • 「如果…就…」規則：例如「連續畫 50 分鐘 → 墨墨提醒休息並做動作」、「拖著墨墨走 → 一路播指定動作，放下時說一句話」；也可以替每隻寵物設專屬規則
  • 主題色與深淺色、快捷面板的區塊與按鈕、快捷鍵
  • 文字大小 75%～150%
  • 設定與角色可以匯出分享給朋友，也能把角色上架到社群寵物庫，或一鍵加入別人分享的角色

開始使用

免安裝，解壓縮後三步就好

下載並解壓縮

點這裡下載 DrawCompanion2.zip（約 36 MB），在檔案上按右鍵 →「解壓縮全部」到一個資料夾，例如 D:\DrawCompanion。

放好

資料夾裡有 DrawCompanion2.exe 和 _internal 資料夾，兩個要放在一起。紀錄、設定、縮圖和影片也都存在這裡，要搬家時整個資料夾一起搬。

雙擊 DrawCompanion2.exe

桌面出現墨墨就完成了。打開 SAI2 開始畫，其他設定都有預設值，用到時才會提醒你。

需要

  • Windows 10 或 11（64 位元）
  • PaintTool SAI Ver.2
  • 縮時錄影要合成影片時才需要 ffmpeg（加入 PATH）
  • 線上圖庫（Unsplash／Pexels）需要免費金鑰；不填也能用本機資料夾的參考圖

第一次執行時

  • Windows 可能顯示「Windows 已保護您的電腦」：按「其他資訊 → 仍要執行」（說明）
  • 請不要直接在 zip 裡雙擊執行，要先解壓縮；也不要把 exe 單獨拿出來
  • 同時只會有一份在執行，重複開啟不會多開
  • 用過測試版：把 zip 解壓縮到原本放 DrawCompanion2.exe 的資料夾、覆蓋舊檔，紀錄與設定都會沿用

第一次執行出現「Windows 已保護您的電腦」？

這是正常的，按兩下就能繼續。之後再開啟就不會出現了。

為什麼會出現

這個視窗（顏色會跟著你的 Windows 主題色）是 Windows 內建的 Microsoft Defender SmartScreen。它會擋下「下載人數還不多、而且沒有數位簽章」的程式。DrawCompanion 是個人開發的免費工具，沒有購買每年數百美元的程式碼簽章憑證，下載的人也還不多，所以 Windows 還「不認識」它。這不是偵測到病毒，視窗裡也沒有說找到任何威脅。

為什麼可以放心

  • 下載檔放在 GitHub Releases；程式內建的自動更新會驗證開發者的數位簽章，檔案被換掉就不會安裝
  • 透過 SAI2 的視窗標題判斷你在畫哪個檔案，不會修改 SAI2 的設定或你已有的作品檔
  • 不需要系統管理員權限，紀錄只存在程式所在的資料夾
  • 請只從這個網頁的下載按鈕下載；從其他地方取得的檔案無法保證內容相同
  • 還是不放心的話，可以先把下載的 zip 上傳到 VirusTotal 用數十種防毒軟體掃描

另一個方法：解壓縮之前在 zip 上按右鍵 →「內容」→ 勾選下方的「解除封鎖」→ 確定，解壓出來的程式就不會再跳出提醒。公司或學校電腦若被管理員鎖定、沒有「仍要執行」按鈕，就需要請管理員協助。

近期更新

每一版修了什麼，方便你決定要不要更新

更新方式：程式會自動檢查新版，在「設定 › 一般 › 更新」按「更新並重新啟動」即可。還在用測試版（beta）的話，請手動下載 DrawCompanion2.zip 一次，解壓縮到原本的資料夾覆蓋舊檔；紀錄與設定都會保留。

常見問題

可以用 Photoshop 或 Clip Studio Paint 嗎？

可以（2.2 起）。在「設定 › 一般 › 繪圖軟體」切換後，動筆時間、每日打卡、作品紀錄與畫布截圖都跟著那個軟體。Photoshop 的截圖需要畫面沒被其他視窗擋住；Clip Studio Paint 開好幾張畫布時以最後開啟的那張為準，截圖是最後一次存檔的樣子，未存檔的新畫布不會記錄。縮時錄影與模組目前只支援 SAI2。

為什麼是 zip，不是單一個 exe？

資料夾版啟動時不用先把整個程式解開到暫存資料夾，開啟比較快，也比較不容易被防毒軟體誤擋；程式內的自動更新也是直接替換這個資料夾。解壓縮後執行 DrawCompanion2.exe，_internal 資料夾請不要刪除或移走。

更新後出問題怎麼辦？

新版連續三次沒有正常啟動，程式會自動退回上一版；也可以到「設定 › 一般 › 更新」按「回到上一版」。上一版完整保存在資料夾裡的 _previous。

需要安裝 Python 或其他程式嗎？

不需要。zip 解壓縮後的資料夾已經包含執行需要的所有東西，直接執行 DrawCompanion2.exe。只有縮時錄影合成影片時需要另外安裝 ffmpeg。

Windows 說「已保護您的電腦」，這個程式安全嗎？

那是 SmartScreen 對「沒有數位簽章、下載人數還少」的程式的提醒，不是偵測到病毒，按「其他資訊 → 仍要執行」即可；詳細步驟見 第一次執行。

我的作品和紀錄會被上傳嗎？

不會。紀錄、作品縮圖、設定都只存在你的電腦（程式所在的資料夾）。程式只會在抓參考圖（大都會博物館、芝加哥藝術博物館、Unsplash、Pexels）、檢查新版、瀏覽社群課程庫與寵物庫、啟用授權，以及你開啟 AI 評鑑時連線；只有你主動上架的課程與角色會上傳，不會收集或傳送你的使用資料。

速寫的倒數為什麼不動？

預設是「下筆時才倒數」：要在 SAI2 已存檔的畫布上下筆才會倒數，停筆看參考圖時會暫停。開始速寫時會自動建立並開啟一張畫布；想改成一直倒數，到小窗的速寫設定或「設定 → 參考圖來源 → 練習畫布」關閉。

寵物擋到我畫畫怎麼辦？

可以把墨墨拖到任何地方；動筆時它會自動變半透明。快捷面板裡的「隱藏 30 分」可以暫時收起來，系統匣圖示隨時叫回來。

可以換成自己畫的角色嗎？

可以。到「設定 → 小幫手」，按陣容的「＋」建立新角色，指定各狀態的圖檔即可；建議 512×512 透明背景的 APNG 或 WebP，也可以用排好多格的序列圖。做好的角色包可以匯出分享給其他人，或在角色的「資料」分頁上架到社群寵物庫；也可以從「社群寵物庫」加入別人畫的角色。
