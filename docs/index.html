SAI2 桌面小夥伴

DrawCompanion 會在 PaintTool SAI2 旁邊安靜地陪著你：自動記錄每張作品畫了多久、每天排好練習任務，速寫和臨摹的參考圖用小窗開著，不占你的畫布。

不占你的畫面

平常只有一隻小寵物；參考圖是可以穿透滑鼠的小窗，單螢幕也能一邊看一邊畫。

功能一覽

以下都是 2.0 測試版的實際畫面（範例資料）

桌面寵物 × 快捷面板

點一下墨墨，常用的都在這

啟動後桌面只會出現墨墨，可以拖到任何地方。點一下打開快捷面板：

  • 今日進度：今天畫了幾分鐘、連續幾天
  • 每日任務：開始、繼續、打卡
  • 最近開啟：作品縮圖，點了直接在 SAI2 開啟
  • 快捷按鈕：速寫、臨摹、快照、縮時錄影…可以自己換

墨墨會依 SAI2 的狀態切換動作，畫太久會提醒你休息；寵物下方顯示本次動筆時間與錄影開關。

參考小窗

速寫、臨摹都在小窗裡

  • 速寫：本機圖庫或線上圖庫自動換圖，下筆時才倒數，停筆看參考圖時暫停
  • 自動建立畫布：一輪速寫一張 A4 畫布，直接在 SAI2 開好
  • 臨摹研究：7 條學習路徑，每堂課有分段步驟、重點與完成檢查
  • 穿透模式：小窗半透明、滑鼠點得穿，疊在畫布上照著畫
  • 按住比對：按住快捷鍵，把你的畫布疊上參考圖比較
  • AI 評鑑（可關閉）：課程打卡時用你自己的 AI 金鑰評分與簡評，決定是否進入下一課（推薦 Google AI Studio，有每日免費額度）
  • 灰階、明度分階、構圖線等檢查工具
今日

今天要練什麼，一眼就知道

主視窗的「今日」頁整理今天的動筆時間、每日任務、本週動筆長條圖與技能動態，也會提醒你哪些技能太久沒練。

  • 任務依每日練習時間與想加強的技能排出，可以換一個或手動加入
  • 每週可以請假，連續天數不中斷
  • 第一次使用時用 30 秒調整練習份量，3 天後依你實際畫的時間再建議一次
成長

每天的投入都看得到

  • 練習月曆：打卡越多顏色越深，點日期看當天做了什麼
  • 動筆時間統計：週、月、半年、一年
  • 技能卡：各技能累積時數與等級
  • 打卡時自動存一張畫布快照，回頭看自己的進步
作品

每張作品畫了多久，還有縮圖

  • 存檔、停筆時自動擷取作品縮圖，清單直接看得到
  • 動筆時間、開著的時間、動筆效率、畫了幾次
  • 技能標籤：這張畫的時間算進哪些技能
  • 另存新檔後可以把兩個檔案合併成一筆；縮時錄影的影片也在這裡
客製化

換成你自己的樣子

  • 自訂角色：放上自己畫的角色，每個狀態可以有不同動畫（PNG／GIF／APNG／WebP）
  • 對話泡泡外觀：用一張圖當泡泡，圈出文字範圍，四角不變形
  • 「如果…就…」規則：例如「連續畫 50 分鐘 → 墨墨提醒休息並做動作」
  • 主題色與深淺色、快捷面板的區塊與按鈕、快捷鍵
  • 設定與角色可以匯出分享給朋友

開始使用

免安裝，三步就好

下載

點這裡下載 DrawCompanion2.exe（約 35 MB）。

放好

放在任何資料夾。紀錄、設定、縮圖和影片都存在這個資料夾，要搬家時整個資料夾一起搬。

雙擊執行

桌面出現墨墨就完成了。打開 SAI2 開始畫，其他設定都有預設值，用到時才會提醒你。

需要

  • Windows 10 或 11（64 位元）
  • PaintTool SAI Ver.2
  • 縮時錄影要合成影片時才需要 ffmpeg（加入 PATH）
  • 線上圖庫（Unsplash／Pexels）需要免費金鑰；不填也能用本機資料夾的參考圖

第一次執行時

  • Windows 可能顯示「Windows 已保護您的電腦」：按「其他資訊 → 仍要執行」（說明）
  • 執行中在工作管理員會看到兩個 DrawCompanion2.exe（啟動器＋本體），是正常的
  • 同時只會有一份在執行，重複開啟不會多開

第一次執行出現「Windows 已保護您的電腦」？

這是正常的，按兩下就能繼續。之後再開啟就不會出現了。

為什麼會出現

這個視窗（顏色會跟著你的 Windows 主題色）是 Windows 內建的 Microsoft Defender SmartScreen。它會擋下「下載人數還不多、而且沒有數位簽章」的程式。DrawCompanion 是個人開發的免費工具，沒有購買每年數百美元的程式碼簽章憑證，測試版下載的人也還不多，所以 Windows 還「不認識」它。這不是偵測到病毒，視窗裡也沒有說找到任何威脅。

為什麼可以放心

  • 程式碼完全公開在 GitHub，任何人都可以檢查
  • 透過 SAI2 的視窗標題判斷你在畫哪個檔案，不會修改 SAI2 的設定或你已有的作品檔
  • 不需要系統管理員權限，紀錄只存在程式所在的資料夾
  • 請只從這個網頁的下載按鈕下載；從其他地方取得的檔案無法保證內容相同
  • 還是不放心的話，可以先把 exe 上傳到 VirusTotal 用數十種防毒軟體掃描

另一個方法：在 exe 上按右鍵 →「內容」→ 勾選下方的「解除封鎖」→ 確定，之後雙擊就不會再跳出提醒。公司或學校電腦若被管理員鎖定、沒有「仍要執行」按鈕，就需要請管理員協助。

常見問題

需要安裝 Python 或其他程式嗎？

不需要。DrawCompanion2.exe 已經包含執行需要的所有東西，下載後直接執行。只有縮時錄影合成影片時需要另外安裝 ffmpeg。

Windows 說「已保護您的電腦」，這個程式安全嗎？

那是 SmartScreen 對「沒有數位簽章、下載人數還少」的程式的提醒，不是偵測到病毒。程式碼完全公開，按「其他資訊 → 仍要執行」即可；詳細步驟見 第一次執行。

我的作品和紀錄會被上傳嗎？

不會。紀錄、作品縮圖、設定都只存在你的電腦（程式所在的資料夾）。程式只有在抓參考圖時才會連線到圖庫（大都會博物館、芝加哥藝術博物館、Unsplash、Pexels），不會收集或傳送你的使用資料。

速寫的倒數為什麼不動？

預設是「下筆時才倒數」：要在 SAI2 已存檔的畫布上下筆才會倒數，停筆看參考圖時會暫停。開始速寫時會自動建立並開啟一張畫布；想改成一直倒數，到小窗的速寫設定或「設定 → 參考圖來源 → 練習畫布」關閉。

寵物擋到我畫畫怎麼辦？

可以把墨墨拖到任何地方；動筆時它會自動變半透明。快捷面板裡的「隱藏 30 分」可以暫時收起來，系統匣圖示隨時叫回來。

可以換成自己畫的角色嗎？

可以。到「設定 → 寵物 → 角色工作室」建立新角色，指定各狀態的圖檔即可；建議 512×512 透明背景的 APNG 或 WebP。做好的角色包可以匯出分享給其他人。
