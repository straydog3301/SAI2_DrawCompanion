# 2.0 發布前實機測試清單

在實際畫圖的電腦上，用打包好的 `DrawCompanion2.exe` 跑一輪。每項打勾或記下問題；發現問題時用 **設定 → 一般 → 關於與問題回報 → 匯出診斷資訊**，把 zip 附在回報裡（不含圖庫金鑰、本機路徑與作品檔名）。

## 安裝
- 把 `DrawCompanion2.exe` 放在 1.x 的 `SAI2_DrawCompanion.exe` **同一個資料夾**：兩版共用同一份紀錄（動筆時間、每日任務）
- 只想先試、不碰正式紀錄：放在另一個空資料夾，或用捷徑加上 `--data-dir D:\某個資料夾`
- 第一次執行時 Windows 可能顯示 SmartScreen 警告（程式沒有數位簽章）：按「其他資訊 → 仍要執行」
- 縮時錄影的影片合成需要 ffmpeg 在 PATH 裡（和 1.x 相同）

## 1. 啟動與常駐
- [ ] 雙擊 exe，寵物出現（記下大約幾秒）
- [ ] 再雙擊一次 exe：不會多開第二份，原本的寵物沒有消失（工作管理員裡執行中會看到兩個 DrawCompanion2.exe，是啟動器＋本體，屬正常）
- [ ] 系統匣有墨墨圖示；工作列與 exe 檔案圖示也是墨墨
- [ ] 設定 → 一般 →「登入 Windows 時自動啟動」打開，重新開機後寵物自動出現
- [ ] 右鍵寵物 →「結束 DrawCompanion」，程式完整關閉（工作管理員裡沒有殘留的 DrawCompanion2.exe）

## 2. 追蹤與 SAI2
- [ ] SAI2 沒開時寵物是「未連結」狀態；打開 SAI2 後切換成待命
- [ ] 開一個已存檔的作品並動筆：寵物下方的計時在走，寵物變成畫圖動作
- [ ] 開一個沒存檔的新畫布並動筆：泡泡提醒「還沒存檔」
- [ ] 快捷面板「最近開啟」點一個作品：SAI2 開著時直接開在 SAI2 裡；SAI2 沒開時先開 SAI2 再開檔
- [ ] 1.x 同時執行時：2.0 顯示暫停記錄；關掉 1.x 後自動繼續（泡泡會說）
- [ ] 作品頁：作品分組合理（桌面、文件底下的作品不會以 Windows 使用者名稱分組）

## 3. 練習
- [ ] 第一次點寵物：面板最上方有「30 秒調整你的練習」卡片；套用後今天的任務照設定重排
- [ ] 速寫：用本機資料夾、Unsplash／Pexels（有金鑰時）各試一次，換下一張、暫停、穿透模式、按住比對
- [ ] 研究：開今天的研究任務，參考圖載入、按「畫布」建立練習畫布、分段提示、打卡
- [ ] 每日任務：達標後打卡、換一個任務、請假

## 4. 縮時錄影
- [ ] 寵物下方紅點開始錄影，畫一段後停止，影片合成完成
- [ ] 第一部影片完成時泡泡顯示存放位置，「更改位置」會開到工具頁

## 5. 客製化
- [ ] 換主題色與淺色模式：主視窗外框與標題列跟著變色（Windows 11）
- [ ] 自訂角色：建立新角色、指定各狀態圖檔，寵物換成自己的圖
- [ ] 對話泡泡外觀：選一張圖、圈選文字範圍，實際跳出的泡泡沒有變形
- [ ] 規則：新增「連續動筆 N 分鐘 → 說話＋做動作」，實際觸發一次
- [ ] 快捷鍵：預設的快捷鍵都能用，沒有和其他程式衝突（被佔用時設定頁會顯示）
- [ ] 設定匯出後，在另一台電腦匯入

## 6. 顯示與操作
- [ ] Windows 顯示縮放 100%、125%、150%（有的話 200%）：寵物、泡泡、面板、參考小窗位置正確、文字沒有被切掉
- [ ] 多螢幕：寵物拖到另一個螢幕後，面板與泡泡跟著出現在同一個螢幕
- [ ] 只用鍵盤：主視窗 Ctrl+Tab 換頁、Tab 移動到按鈕時有焦點框

## 7. 長時間使用
- [ ] 開著畫一整天：工作管理員裡的記憶體沒有持續上升、CPU 平時接近 0%
- [ ] 隔天（過了換日時間）任務自動換成新的一天
- [ ] 設定 → 一般 → 開啟錯誤記錄：沒有記錄，或把內容回報

## 回報格式
```
項目：（例如 2. 追蹤與 SAI2 第 4 項）
現象：
重現步驟：
附件：診斷資訊 zip、截圖
```
